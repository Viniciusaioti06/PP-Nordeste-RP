# Design institucional completo

O padrão visual da nova página principal foi estendido para:

- inscrição;
- consulta de status;
- área do candidato;
- login interno;
- configuração inicial;
- painel administrativo;
- análise individual de candidatos.

O novo brasão foi aplicado como identidade principal.

As mudanças são exclusivamente visuais e de microinteração. Serviços, Supabase, autenticação, permissões, auditoria e Edge Functions foram preservados.
